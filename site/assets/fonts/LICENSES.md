# Web font licenses

The Happy Photon site self-hosts reviewed subsets of the same font sources used
by the desktop application. The subsets remain licensed under the SIL Open
Font License 1.1.

- Sora: copyright 2019 The Sora Project Authors.
- Hanken Grotesk: copyright 2021 The Hanken Grotesk Project Authors.
- JetBrains Mono: copyright 2020 The JetBrains Mono Project Authors.

The complete license texts are included in the `licenses/` directory beside
this file. None of the current source licenses declares a Reserved Font Name.
