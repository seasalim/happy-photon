IS IT A FIT?

For photographers who want a smaller everyday workflow

Happy Photon is designed for personal RAW, JPEG, and mixed-format shoots stored in ordinary Windows folders. It focuses on browsing, selecting, global photographic adjustments, presets, and export rather than reproducing a full professional suite.

  • No import step: browse photographs where they already live.
  • No required account, subscription, advertising, or product telemetry.
  • Edits, ratings, flags, and color labels stay in a local Happy Photon catalog.
  • Exports create new JPEG, PNG, or WebP files.

FILES AND CAMERAS

JPEG and RAW are both first-class inputs

Standard image support includes JPEG (commonly shown as JPG), PNG, BMP, GIF, TIFF, and WebP. RAW support is verified for CR2/CR3, NEF, ARW, DNG, RAF, and RW2. NRW, ORF, and PEF open through the same decoder but are not part of the verified set.

Check your camera.

RAW decoding uses the bundled, audited LibRaw 0.22.2 generation. A listed extension does not guarantee every camera model or compression mode, especially from newer cameras. HEIC/HEIF support can also vary with the available codec. Nikon high-efficiency (HE and HE*) NEF files are not supported and are reported as unsupported rather than opened.

ORIGINAL-FILE SAFETY

Edits are instructions, not replacements

Happy Photon stores edit instructions, flags, ratings, and color labels in its local catalog. It does not write those changes into the original photograph. Export creates a separate file, and export targets that would overwrite a loaded original are refused.

Happy Photon is pre-1.0 software. Keep normal backups of important photographs and learn the workflow with a copied shoot if you want an extra margin of safety.

CURRENT SCOPE

Know what the first release leaves out

The current editing workflow uses global adjustments. It does not include local masks, lens or perspective correction, layered compositing, HDR output, custom output color profiles, mobile synchronization, or Photoshop integration.

COMMON QUESTIONS

Before you install

Does Happy Photon work on Windows 11?

Yes. Happy Photon supports Windows 10 version 1809 or later, including Windows 11 on x64 computers.

Does Happy Photon replace Lightroom?

It covers a narrower everyday folder-to-export workflow. It can import ratings, pick and reject flags, and color labels from Lightroom Classic, but it does not migrate Lightroom edits or reproduce Lightroom’s full catalog, cloud, masking, and ecosystem features. Read the Lightroom import guide.

Can I edit ordinary camera JPEGs?

Yes. JPEG-only, RAW-only, and mixed-format folders all use the same browsing, selection, non-destructive editing, and export workflow.

Where are my changes stored?

Edits, flags, ratings, and presets default to the Happy Photon catalog under Pictures; regenerable previews and thumbnails use %LOCALAPPDATA%\Happy Photon\cache. Settings can stage a catalog move. Store users who opt into an AppData catalog see an uninstall-removal warning.
