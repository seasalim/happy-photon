IS IT A FIT?

A local workflow that stays understandable

Happy Photon is for photographers who keep RAW and JPEG shoots in ordinary folders and want to move from review to finished export without adopting a large catalog or cloud ecosystem.

  • GPL-3.0-or-later source code and public build instructions.
  • No required account, subscription, advertising, or product telemetry.
  • Local catalog storage and non-destructive edits.
  • Focused global editing tools, presets, ratings, flags, color labels, filters, and burst grouping.

INSTALL ON LINUX

Run the portable x64 release

  1. 01

    Download the Linux archive

    Choose the current linux-x64 archive from the verified GitHub release linked on the download page.

  2. 02

    Verify and extract it

    Compare the archive with SHA256SUMS.txt, then extract it to a folder you control.

  3. 03

    Run Happy Photon

    Launch the HappyPhoton executable and choose an existing folder of photographs. The release is portable rather than a native distribution package.

Current packaging boundary.

The initial Linux release does not provide native package-manager or desktop integration. The project publishes one verified x64 portable archive and invites specific compatibility reports.

FILES AND CAMERAS

Use JPEG, RAW, or both

Standard image support includes JPEG (commonly shown as JPG), PNG, BMP, GIF, TIFF, and WebP. RAW extensions include CR2/CR3, NEF/NRW, ARW/SRF/SR2, DNG, RAF, ORF, RW2, and PEF.

Extension is not the whole compatibility story.

RAW support depends on the camera model and capture mode. Happy Photon uses the bundled LibRaw 0.21.1 generation from early 2023, so verify important cameras—especially newer bodies—before relying on the workflow.

LOCAL BY DESIGN

Originals stay in their folders

Happy Photon reads photographs where they already live. Edits, flags, ratings, color labels, and presets default to ~/Pictures/Happy Photon Catalog/, while regenerable previews and thumbnails use ~/.cache/happy-photon. Settings can stage a catalog move. Export makes separate files and refuses a target that would overwrite a loaded original.

Because Happy Photon is pre-1.0 software, keep normal backups of important photographs and test the formats and cameras that matter to you.

CURRENT SCOPE

A focused editor, not a complete desktop suite

The first release does not include local masks, lens or perspective correction, layered compositing, HDR output, custom output color profiles, institutional digital-asset management, or native distribution packages.

COMMON QUESTIONS

Before you download

Is Happy Photon open source?

Yes. Happy Photon is licensed GPL-3.0-or-later. The repository includes source code, build instructions, dependency notices, and the contribution process.

Does the Linux release install system packages?

No. The initial release is a portable archive, not a native package-manager installation.

Can I report my camera or distribution?

Yes. Use the project’s GitHub issue forms for a reproducible compatibility failure and Discussions for broader workflow or packaging feedback.
