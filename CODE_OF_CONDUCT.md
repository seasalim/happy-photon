# Code of Conduct

Happy Photon is committed to a welcoming, constructive project community.

## Expected behavior

- Treat other participants with respect and patience.
- Critique ideas and code without attacking people.
- Make room for different experience levels and perspectives.
- Respect privacy, attribution, licensing, and consent around photographs.
- Accept moderation decisions and correction in good faith.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, doxxing, deliberate
intimidation, and sustained disruption are not tolerated. Publishing another
person's private information, photographs, credentials, or agent tokens
without permission is also prohibited.

## Scope and enforcement

This policy applies in project repositories, issue trackers, discussions,
reviews, and project-represented public spaces.

Report conduct concerns privately to the repository maintainers using the
available GitHub moderation or private reporting channel. Maintainers may
edit or remove contributions, lock discussions, issue warnings, or temporarily
or permanently restrict participation. Reports will be handled as
confidentially as practical.

Maintainers must avoid conflicts of interest when reviewing a report and seek
another neutral reviewer when possible.
